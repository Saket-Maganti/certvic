# Ethics And Artifacts

- Zero-cost reproducibility is a project constraint.
- Public datasets are used through pointer-only manifests unless redistribution
  is verified.
- Paid annotation is not part of the core workflow.
- Human review uses anonymized reviewer IDs.
- Non-rehostable pixels are not included in public artifacts.
- The project does not make deployment claims.
- Model limitations are documented in model/eval cards.
