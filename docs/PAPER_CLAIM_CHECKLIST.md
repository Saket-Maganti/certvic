Before any result cell leaves `[RESULT REQUIRED]`, confirm ALL of:

- [ ] Real ADE20K split + real image source (not smoke/synthetic).
- [ ] Edits generated by a photorealistic engine and passing quality gates.
- [ ] Human visual review passed; IAA reported (Cohen kappa / majority); no single-rater fields.
- [ ] Non-mock, non-baseline open-local provider (zero-cost, free compute).
- [ ] Predictions scored; raw outputs preserved.
- [ ] Anytime-valid CS available; bootstrap CI used only descriptively.
- [ ] Certification policy passes (min n overall/by-family, parse-failure max, control spurious-flip max, evidence status, provider type).
- [ ] Claim wording approved (no forbidden phrases); descriptive vs certified separated.
- [ ] Power analysis justifies n; optional-stopping behavior reported.
- [ ] No deployment/safety/causal-understanding claims.

Certified claim template (only if all boxes checked and CS lower bound > threshold):

intervention-consistency gap lower bound exceeds the threshold for this run on
