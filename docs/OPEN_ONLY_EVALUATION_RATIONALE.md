# Open-Only Evaluation Rationale

CertVIC keeps the core workflow zero-cost and reproducible. The protocol is
model-agnostic, but claims are scoped to open VLMs actually run.

Rationale:
- public/free data pointers and recipe-first manifests
- local CPU checks and optional free-GPU execution
- no paid APIs, paid cloud, paid datasets, paid annotation, or hidden services
- no frontier-model generalization unless those systems are actually run later

Limitation:
The absence of closed/frontier models is an explicit limitation. It is not a
claim that the result generalizes to unrun VLM systems.
