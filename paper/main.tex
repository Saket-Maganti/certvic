\begin{abstract}
CertVIC is a protocol for certified, confound-controlled measurement of visual
decision updates in vision-language models. The method admits an edited
real-image pair as evidence only after an item-validity certificate checks edit
quality, edit detectability, human realism, single-factor validity,
answerability, and leakage. It then estimates the intervention-consistency gap
and certifies it with anytime-valid certification under optional stopping.
Empirical values remain [RESULT REQUIRED] until real, certificate-eligible open
VLM runs exist.
\end{abstract}
