\section{Title and Thesis}

\paragraph{Working title.}
CertVIC: Certified, Confound-Controlled Measurement of Visual Decision Updates
in Vision-Language Models.

\paragraph{Thesis.}
The paper is not a benchmark paper, not a dataset paper, and not a generic
robustness claim. CertVIC asks whether a vision-language model performs a
\emph{visual decision update}: after the visual world changes in a
photorealistic, human-validated, single-factor intervention, does the model
update the answer it would otherwise give?

\paragraph{Methodological moat.}
An item-validity certificate is load-bearing. It decides whether an original/edit
pair is admissible evidence before the intervention-consistency gap is measured
and before anytime-valid certification is interpreted. Edit detectability is a
first-class confound: if the edit is easy to detect as an artifact, the pair
does not support paper claims.
