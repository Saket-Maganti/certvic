\paragraph{Specificity controls.}
We evaluate irrelevant-edit specificity as a separate gate from the main update-gap result. InternVL and LLaVA pass the existing irrelevant-edit specificity gate, while Qwen2.5-VL-7B fails it under the V1 control set with 12 flips out of 94 items. A stricter V9 Spurious V2 control set has been prepared for a preregistered rerun, but those GPU results are not yet available. Until that run is imported and validated, the paper must not claim all-model specificity.
