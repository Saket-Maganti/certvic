\section{Open-Only Evaluation Scope}

The core empirical workflow is zero-cost and reproducible: public/free data
pointers, local CPU checks, optional free-GPU edit generation, and open VLMs
actually run by the study. The protocol is model-agnostic, but empirical claims
are scoped to the open models that produce certificate-eligible results.

Closed or frontier comparisons are optional future, non-core extensions. Their
absence is a limitation, not a hidden claim about private systems. CertVIC does
not generalize beyond the model set, data sources, edit families, and item
certificates that are actually executed and audited.
