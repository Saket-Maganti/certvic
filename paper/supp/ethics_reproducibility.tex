\section{Ethics and Reproducibility}

CertVIC is designed around zero-cost reproducibility: local CPU workflows, free
GPU execution when manually requested, public datasets, no paid annotation, and
no paid APIs. Dataset pixels are pointer-only by default when redistribution is
not verified. Human review files should use anonymized reviewer identifiers and
should not contain private rater information.

The artifact release is recipe-first. Non-rehostable pixels are not redistributed
unless a separate license check confirms redistribution is allowed. Model cards
and eval cards document open/local/free status and limitations.

CertVIC does not make deployment claims. The method evaluates a controlled
research benchmark under declared assumptions.
